This page documents the GameBoy SpiderCart development. The SpiderCart is a GameBoy Cartridge that tries to do more then any known GameBoy Cartridge before it. It is fully open source, with the hardware and software designs freely available for anyone to use and modify.

It can function as a Flash Cart, loading ROMs directly from an SD cart. But wait, there is more. It can also run various things previously impossible on the GameBoy. This thanks to the co-processor in the cartridge.
