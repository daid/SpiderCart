# SpiderCart

The SpiderCart is the ultimate GameBoy and GameBoy Color flash cartridge. It has more functionality cramped in there then any other flash cart on the market, being legs ahead of it. Not only does it run all the games you would expect.

## Features

* RTC: Sometimes called the Timer or Clock. Used by pokemon crystal but also a few other games. This keeps time even when the gameboy is off.
* Rumble: One of the few, or only? Flash cartridge that supports rumble. Enjoy pokemon pinball as it was intended.
* Accelerometer: The only flash cart that can read the orientation of your gameboy. Allowing to run Kirby Tilt 'n' Tumble the way it was intended to be played!
* Micro SD card slot for ROM storage.
* USB-C connector for easy updating of ROM or even directly loading ROMs from your PC during homebrew development.
* Capable co-processor allowing to push the gameboy beyonds its intended limits.
* Support to run pico-8 games (with some limitations)
* Fully customizable [open-source firmware and hardware](https://github.com/daid/SpiderCart)
